# WebP Converter for Portfolio

Скрипт на Python для автоматической пакетной конвертации фотографий формата JPG/JPEG в современный формат **WebP**. Оптимизирован для подготовки медиа-контента для веб-сайтов и портфолио: обеспечивает высокое сжатие без видимой потери качества.

## 🚀 Особенности

- **Конфигурация через `.env`**: путь к папке и параметры задаются в одном конфигурационном файле.
- **Сохранение в ту же папку**: сконвертированные `.webp` файлы сохраняются рядом с исходными фото.
- **Умная обработка ориентации**: автоматический поворот фото по EXIF-тегам (фото с телефонов и камер не переворачиваются).
- **Высокая степень сжатия**: используется метод оптимизации `method=6` библиотеки WebP.
- **Пропуск существующих**: не перезаписывает уже обработанные файлы (можно настроить).
- **Подробная статистика**: показывает сэкономленный размер для каждого файла и общий итог.

## 🛠️ Установка и запуск

### 1. Клонирование / Переход в папку проекта

```bash
cd webp-parser
```

### 2. Создание и активация виртуального окружения (рекомендуется)

**Windows (PowerShell):**
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

**Linux / macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

### 4. Настройка `.env`

Создайте файл `.env` на основе примера `.env.example`:

**Windows (PowerShell):**
```powershell
Copy-Item .env.example .env
```

**Linux / macOS:**
```bash
cp .env.example .env
```

Откройте файл `.env` в любом редакторе и укажите путь к вашей папке с фотографиями:

```dotenv
# Путь к папке с фотографиями (абсолютный или относительный)
PHOTOS_DIR=C:/Users/username/Pictures/Portfolio

# Качество сжатия WebP (1-100, по умолчанию 80)
WEBP_QUALITY=80

# Искать во вложенных подпапках (true / false)
RECURSIVE=true

# Пропускать файлы, если .webp уже существует (true / false)
SKIP_EXISTING=true

# Удалять исходные JPG после конвертации (true / false)
REMOVE_ORIGINALS=false
```

### 5. Запуск скрипта

```bash
python main.py
```

## 📤 Как запушить в Git (GitHub / GitLab)

1. Инициализируйте репозиторий (если еще не инициализирован):
   ```bash
   git init
   ```

2. Добавьте файлы в индекс:
   ```bash
   git add .
   ```

3. Сделайте первый коммит:
   ```bash
   git commit -m "feat: init webp converter script"
   ```

4. Привяжите удаленный репозиторий и отправьте код:
   ```bash
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
   git push -u origin main
   ```

> **Важно:** файл `.env` с вашими локальными путями автоматически игнорируется через `.gitignore` и не попадет в репозиторий. В репозитории будет только `.env.example`.
